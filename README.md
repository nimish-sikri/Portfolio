## Features

- **Animated Typing Intro** - Cycling role titles in sidebar
- **Dark / Light Theme** - Toggle with persistent preference
- **Working Contact Form** - Powered by Web3Forms
- **Glass Pill Navigation** - Smooth sliding active tab indicator
- **Project Tooltips** - Hover to see project descriptions
- **Scroll Reveal Animations** - Sections animate on scroll
- **Back to Top Button** - Smooth scroll navigation
- **Resume Download** - One-click PDF download
- **Coding Profiles** - Links to LeetCode, CodeChef, Codeforces, GFG
- **Google Analytics** - Visitor tracking integrated
- **SEO Optimized** - Open Graph and Twitter Card meta tags
- **Fully Responsive** - Works on all devices

## Sections

- **About** - Bio, services, and coding profiles
- **Resume** - Education, experience, skills, achievements, and positions of responsibility
- **Portfolio** - Projects with tech stack tags and GitHub links
- **Contact** - Working contact form with Google Maps

## Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- Web3Forms (Contact form)
- Google Analytics
- Ionicons

## Setup

```bash
git clone https://github.com/nimish-sikri/Portfolio.git
cd Portfolio
# Open index.html in browser or start a local server
python -m http.server 5500
```
